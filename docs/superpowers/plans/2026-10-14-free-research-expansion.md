# 免費人物消息與公司公告開工計畫

> **For agentic workers:** 執行時使用 superpowers:executing-plans，按下列核取項目逐項實作與驗證。本文件是使用者要求先交付的開工計畫；本輪不修改產品或雲端設定。

**Goal:** 在不新增付費資料服務的前提下，擴充可核對的人物消息來源，恢復公開研究內容的更新流程，維持公司公告更新可靠性。

**Architecture:** 沿用現有研究批次、私有候選、審核發布器及網站讀取器。免費來源先進私有待審區；已核對的來源、摘要與分類才透過既有受控流程公開。公告與人物來源各自保存成功時間和失敗狀態。

**Tech Stack:** 現有 Python、requests、研究 JSON schema、Cloud Run Job、Cloud Scheduler、GCS、Flask/Jinja；優先使用標準函式庫，不新增付費 API、模型服務或常駐伺服器。

**Spec:** 本文件的「範圍與約束」為本次開工規格，依使用者「維持免費，剩下的幫我處理，先給開工計畫表」制定。

## 範圍與約束

- 不訂閱付費 X API、資料商、代理服務或摘要 API，不使用試用到期轉付費服務。
- 免費指新增資料來源與工具不付費；既有 GCP 執行、儲存、流量仍依帳戶計費，不能宣稱整個網站零成本。先核對用量與免費額度；不擅自升級資源或大幅增加排程頻率。
- 名單與技術選擇由執行者處理。第一批以合計 10 個有效人物／機構來源為目標，最多評估 20 個候選；須有正確身分、可取得原文、時間與至少一筆可核對內容。不以空白人物卡充數，未達標明列缺口。
- 優先補齊現有三個 X 來源與兩個 YouTube 舊來源；另選台美股相關原創研究者及具有官方揭露的機構。每個新增對象需個別來源證據，不承諾尚未驗證的帳號可用。
- RSS／Atom、公開官網、YouTube 官方免費取得方式及官方揭露來源先做連通與使用條件檢查。既有免費 X 來源只標示有限涵蓋，不保證即時或完整。
- 候選不自動成為已核對觀點、共識或推薦。沿用操作者審核邊界；可自動整理待審清單，不能自動核准或公開候選。
- 首輪由執行者逐筆核對並準備可審閱發布內容，依既有發布權限流程操作。之後每日自動抓取不等於每日自動審核；不得以本次對話承諾無人值守的人工作業。
- 顯示原文發布、抓取、核對時間；新聞轉述、原創觀點、交易揭露與機構持倉分開。只有標題或節目介紹時不推論買賣立場。
- 不公開完整轉載、私有候選、登入資訊或審核備註。保留來源故障時的前次可用資料及原始成功時間。
- 先從執行當下的正式來源版本建立隔離變更；目前工作目錄 8f42b93 比正式功能舊，禁止直接用它覆蓋正式站。保留本次修復證據與所有既有工作。

## 開工順序與交付

| 階段 | 工作 | 完成條件 |
|---|---|---|
| 1 | 核對正式版、研究 Job、映像保留標籤、既有費用及排程 | 確認正確基底與費用邊界；有可用回退版本 |
| 2 | 篩選人物與機構、逐一測試免費來源 | 來源清冊記錄姓名、身分證據、原文入口、取得方式、更新頻率、實測狀態；有效來源目標 10 個 |
| 3 | 接入最小必要的免費來源取得方式 | 原文 ID 去重、時區、來源身分與錯誤保留測試通過；新內容只進私有待審區 |
| 4 | 整理並核對第一批新內容，接通既有發布流程 | 每筆摘要、對象、證券與立場可回查原文；缺證據保留待審；不降低審核門檻 |
| 5 | 改善人物頁和資料更新說明 | 人物篩選可用；抓取與核對時間清楚；無內容／來源失敗／尚未核對不混淆 |
| 6 | 加固公告與研究更新的失敗處理 | 重試有上限；失敗不覆蓋好資料；獨立保留各來源成功時間；工作映像免於既有清理規則 |
| 7 | 候選驗證、正式發布與排程驗收 | 相關測試、桌面／390px、私有資料隔離、快照雜湊及實際流量驗證完成；自然排程另有成功證據才稱長期鏈路已驗證 |

## 執行與驗收清單

- [ ] 每項非簡單邏輯先加可重現失敗的測試，確認原版失敗，再做最小修正，最後跑相關回歸。
- [ ] 重複貼文／跨來源轉載：以來源身分與不可變 ID 去重，不重複計入觀點。
- [ ] 帳號改名／冒名／不同作者：身分不一致時拒絕更新，不錯掛人物。
- [ ] HTTP 429／逾時／壞資料／空來源：保留前次資料，標示來源故障，不偽造成功時間。
- [ ] 缺時區／影片無逐字稿／只有標題：保留原始資訊，不推斷股票代碼或投資立場。
- [ ] 待審／登入後內容：匿名端不能讀取；共識只計入符合既有核對契約的資料。
- [ ] 舊版清冊／審核版本變更／並行發布：版本與 generation 不一致時拒絕覆寫。
- [ ] 執行相關測試、正式前候選頁及桌面／390px 瀏覽器驗證；具體測試命令使用實際隔離工作目錄與專案 Python。
- [ ] 發布後讀回 GCS 雜湊、核對 status.traffic、功能旗標、兩頁顯示時間與筆數，以及研究 Job 執行結果。
- [ ] 後續自然排程未發生時明列未驗證；不將手動補跑寫成自然排程成功。
